# Formal64 qualitative asset status

## Approved task illustrations

Two clear non-result illustrations were added under `illustrative_task_only/` after user authorization to use representative scenes when exact trajectory reconstruction remains difficult. They depict the peg-in-hole task and contain no labels, GUI, debug overlays, oracle annotations or outcome claims.

## Integrity boundary

The pair-3, pair-14 and pair-42 official outcome figures are deliberately **not** included. The recorded Formal64 bundle retains initial snapshots and outcome summaries but no official per-step action trace. Current deterministic replay work still has an unresolved state/control mismatch: pair-14 `torque-original` did not reproduce the saved strict success. Per `docs/FORMAL64_THESIS_RENDER_CORRECTION_REQUEST.md`, divergent replay frames cannot be captioned as official outcomes.

The images in this directory therefore support only task and method exposition. They must not be used as visual evidence for a visual-vs-torque result, success, failure, or ejection.
